# Optimized 64-bit ALU in Verilog

## Overview

Designed and optimized a 64-bit Arithmetic Logic Unit (ALU) in Verilog HDL with emphasis on arithmetic performance and RTL-level power optimization techniques.

## Features

- 64-bit arithmetic and logical operations
- Carry Look-Ahead Adder (CLA)
- Operand isolation
- Clock gating concepts
- Modular RTL design

## Optimization Techniques

### Carry Look-Ahead Adder
Implemented CLA-based carry generation to improve arithmetic operation speed compared with conventional ripple-carry addition.

### Operand Isolation
Reduced unnecessary switching activity by preventing unused operands from propagating through datapath logic.

### Clock Gating
Applied clock-gating concepts to reduce unnecessary sequential switching activity.

- Combinational logic optimization
